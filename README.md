# acme-knowledge

The knowledge repository of Acme, a made-up company. It is the example from
[Docsworth](https://github.com/docsworth/docsworth), on GitHub so that the pull requests
its agents open are real. Each page has one owning team, set in `CODEOWNERS`, and a review
date. Agents cite only pages that are canonical and inside their review window.

The pull requests here were opened by Claude Code with the Docsworth plugin, in the
recordings on [docsworth.github.io](https://docsworth.github.io). Nothing here describes a
real system.
